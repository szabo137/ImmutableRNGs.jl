ImmutableRNGs.Philox4x32 — Type
Philox4x32(key, counter)

A Philox 4x32 RNG with 10 rounds, backed by PhiloxRNG.jl.

See Salmon et al., Parallel Random Numbers: As Easy as 1, 2, 3.

Use directly with rand_step. Supported sample types are UInt32, Float32, and Float64.

source
ImmutableRNGs.Splitmix64 — Type
Splitmix64(seed)

A SplitMix64 counter-based RNG.

See Steele, Lea, and Flood, Fast Splittable Pseudorandom Number Generators.

Use directly with rand_step. Supported sample types are UInt64, Float64, and Int.

source
ImmutableRNGs.StatefulRNG — Type

Compatibility wrapper that exposes the legacy Random.rand API on top of the immutable backend.

The wrapper owns the current state, but the underlying backend remains purely functional.

source
Base.rand — Method

Legacy Random.rand compatibility layer.

All old-style calls are delegated to the immutable backend while the wrapper stores the current state explicitly.
